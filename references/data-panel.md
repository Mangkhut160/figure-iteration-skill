# 数据面板（结果小图）

## 1. 纪律

- 只用 profile 的「数字与口径」认可的数（例如冻结配置之后的正式结果、规定的重复数）；每个数都能追到实验记录里的条目或单一的结果文件。快照数字、单个重复、不同配置拼出来的最好数，都不填。
- 缺的写 TODO，对应的柱子继续占位。可以分批：填好的组先改。
- 同一组的几个水平在同一批试验上跑（配对）。
- 写清重复改变了什么：它决定误差棒代表什么。例：重复只改变训练的随机性、评估集不变时，误差里就不含评估集本身的波动，图注里写明。
- 不确定度和正文表格用同一种：均值 ± std，或均值加 min–max（重复数很少时更直观），二选一。
- 只标论点要用的那个数，不给每根柱子都标。
- 图上的数和摘要、引言、表格一致（`references/content-sync.md` §4）。
- 实验记录或结果文件不在手边时：请用户给条目编号或结果文件的路径，或者到有它们的仓库里查。
- 用户自己在编辑软件里填了数：那是他的手改，保留；在回复里指出出处待补，`claims_vs_code.md` 里标「待溯源」；投稿前必须换成能追溯的数。
- 「只是内部看一下」也不例外：论文用的图（`fig.vN`）里不放快照数。可以做的是：冻结了的组先填，其余继续占位；另写一份状态说明（md），列出快照数和出处，标明是快照。用户听完理由仍要一张带数的图，就另出一张，不进版本链（文件名如 `<图号>_snapshot_<日期>.png`），图上醒目地标出 SNAPSHOT – NOT FOR PAPER。

## 2. 向用户要数

把 `$SK/templates/data_fill_form.md` 改成这张图的组和水平，写成单独的 md 放在交付目录，请用户填（先选口径，再填数）。

## 3. 填进 pptx（用原生形状画的柱图）

先看清这个组：`python $SK/scripts/pptx_inspect.py <底稿副本> --group '<结果组的名字> '`（名字从不加 `--group` 的列表里读）。

- 刻度从图里量，不写死。组里横跨整个图的水平线是网格线；轴标签（如 `0`、`50`、`100`）只用来认哪条线是哪条（标签框的中心和线差 0.1 pt 左右，别拿它算）。由网格线算出 0 线的 y 和每个单位对应多少 pt（百分数的图：`(y0 − y100) / 100`）。柱子的共同底边应该等于 0 线，不等就停下来看。
- 柱子按填充色认（每个系列一种颜色，从 `pptx_inspect.py` 读），只取底边落在 0 线上的（小图例的色块常和柱子同色，要排除），每种颜色的根数要等于组数。按 x 排序、每组几根一起，再和组名文字的中心核对（`text_of` 是精确匹配，名字有包含关系的组名不会混）。
- 柱高 = 数值 × 每个单位的 pt，柱顶 = 0 线 − 柱高；改 `top` 和 `height`，底边不动。
- 数字标签：用 `K.texts(组, 'xx.x')` 取出现成的占位标签，按中心 x 对到柱子，改字，放在柱顶上方一小段距离（保持占位标签原有的间距）。数量不对就停下来看：论点只用某个数时，标签比柱子少是正常的。柱子接近满刻度时，标签会碰到最大值那条网格线：把各组的数字标签一起挪到那条线上方（留一点间隙），各组标签保持同一高度。柱子很矮时，标签不要压到 0 线。
- 误差标记：细线（复制一条现成的线），横帽宽约为柱宽的一半。一个刻度单位对应的高度很小时，小的误差几乎看不见，图注里要写清标记是什么。
- 改完读回核对：对新文件再跑一次 `pptx_inspect.py --group '<结果组的名字> '`，逐根看柱高是否等于数值 × 刻度；论点用到的两个系列的差是否等于摘要里的数；放大看标签和网格线有没有压在一起。

## 4. 独立的数据图

整张都是数据图（如结果章的曲线、柱状图）时，用项目既定的绘图后端（常见是 matplotlib），设 `pdf.fonttype: 42`（不能出 Type 3），字体和字号照 profile。数据直接从结果文件读，脚本放在图目录里，图注写明试验数和重复数。
